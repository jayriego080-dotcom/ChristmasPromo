# PINOY LM SHOP — Christmas Special 2026

A static, mobile-responsive promo rules website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — website content
- `style.css` — layout and responsive styling
- `app.js` — mobile navigation behavior

## Upload to GitHub
1. Create a new GitHub repository (for example: `pinoy-lm-shop-christmas`).
2. Upload `index.html`, `style.css`, `app.js`, and this `README.md` to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your public URL will appear in the Pages settings.
